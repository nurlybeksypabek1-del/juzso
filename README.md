# Мой учебный план

Простой адаптивный планировщик для телефона и ноутбука.

## Публикация на GitHub Pages
1. Создай новый публичный репозиторий на GitHub.
2. Загрузи в корень репозитория все файлы из этой папки.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main` и папку `/ (root)`, затем нажми **Save**.
6. Подожди публикации — GitHub покажет ссылку на сайт.

## Установка на телефон
Открой опубликованный сайт в браузере телефона:
- Android/Chrome: меню браузера → «Установить приложение» или «Добавить на главный экран».
- iPhone/Safari: «Поделиться» → «На экран Домой».

Сайт можно открыть и без интернета после первой загрузки (если браузер сохранил кэш).

## Как работает сохранение
- Отметки и добавленные задачи сохраняются в браузере на конкретном устройстве.
- Они **не синхронизируются автоматически** между телефоном и ноутбуком.
- Для переноса нажми значок экспорта ↥ на первом устройстве, затем значок импорта ↧ на втором и выбери скачанный JSON-файл.
- Не очищай данные сайта в браузере, если хочешь сохранить локальный прогресс.

## Важно
Список заданий и занятий заполнен по предоставленному расписанию. Время на домашние задания намеренно не зафиксировано: сначала нужно распределить реальные объёмы так, чтобы не жертвовать сном. Сокращения ЛС/КС/ОЖ/СТ/НТ оставлены как есть.
